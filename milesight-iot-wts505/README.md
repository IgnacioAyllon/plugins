# WTS505 - Weather Station

The WTS505 is an all-in-one LoRaWAN® weather monitoring system designed for comprehensive atmospheric condition monitoring. This professional weather station measures temperature, humidity, wind speed, wind direction, barometric pressure, and rainfall. Featuring an IP67-rated enclosure, the WTS505 is built to withstand challenging weather conditions and is suitable for deployment in meteorology, smart agriculture, smart building, and various outdoor environmental monitoring applications.

## Features

- **Multi-sensor Integration**: Temperature, humidity, barometric pressure, wind speed, wind direction, and rainfall measurements
- **LoRaWAN® Connectivity**: Long-range wireless communication for remote monitoring
- **Rugged Design**: IP67-rated enclosure for weather-resistant operation
- **Operating Temperature**: -20°C to 60°C
- **Compact Form Factor**: 140 x 50 x 248 mm dimensions
- **Battery Powered**: Built-in battery monitoring for operational reliability
- **Easy Installation**: All-in-one design simplifies deployment in various scenarios

## Use Cases

- Meteorological monitoring
- Smart agriculture and precision farming
- Smart building environmental control
- Outdoor environmental monitoring
- Weather data collection for research and analysis

## Thinger.io Integration

The WTS505 integrates seamlessly with Thinger.io through LoRaWAN connectivity, enabling real-time weather data visualization, analytics, and alerts for comprehensive environmental monitoring solutions.

## Requirements

A LoRaWAN server is required to communicate the WTS505 into Thinger.io, some options are:

- [The Things Stack](https://www.thethingsindustries.com/stack/)
- [LORIOT](https://loriot.io/)
- [ChirpStack](https://www.chirpstack.io/)

Alongside, the corresponding plugin for the selected LoRaWAN server needs to be installed in your Thinger.io instance.

## Get Started

### Installation

Look for the plugin in the [Thinger.io Plugin Store](https://marketplace.thinger.io/) and install it in your Thinger.io instance. Once the plugin is installed a new Product will be created for this device.

### Configuration

The Product is already preconfigured, check that the auto provision prefix matches the one selected in your LoRaWAN server plugin in Thinger.io, or change it to your desire.

### Usage

Start sending uplinks for autoprovisioning devices and buckets.
This product also provides a predefined dashboard and downlinks.
