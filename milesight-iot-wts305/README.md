# WTS305 - Weather Station

The WTS Series are an all-in-one LoRaWAN® weather monitoring system for various atmospheric conditions, such as temperature, humidity, wind speed, wind direction, barometric pressure and rainfall. Designed for outdoor deployment, the WTS305 provides reliable environmental monitoring with IP67-rated protection, making it suitable for agricultural, meteorological, smart city, and industrial applications.

## Features

- **Temperature Monitoring**: Range -40°C to 85°C with ±0.3°C accuracy and 0.1°C resolution
- **Humidity Sensing**: Capacitive sensor covering 0% to 100% RH with ±5% RH accuracy
- **Wind Speed & Direction**: Real-time wind measurements for weather tracking
- **Barometric Pressure**: Atmospheric pressure monitoring
- **Battery Powered**: Integrated battery monitoring for maintenance planning
- **IP67 Enclosure**: Weather-resistant design for harsh outdoor environments
- **LoRaWAN Connectivity**: Long-range wireless communication with low power consumption
- **Compact Design**: 140 x 50 x 248 mm dimensions for easy installation
- **Wide Operating Temperature**: -20°C to 60°C operational range

## Use Cases

- Agricultural monitoring and smart farming
- Meteorological data collection
- Smart city environmental sensing
- Industrial site weather monitoring
- Construction site conditions tracking
- Outdoor event planning and management
- Research and climate studies

## Thinger.io Integration

The WTS305 integrates seamlessly with Thinger.io through LoRaWAN network servers, enabling real-time weather data visualization, analysis, and alerting capabilities.

## Requirements

A LoRaWAN server is required to communicate the WTS305 into Thinger.io, some options are:

- [The Things Stack](https://www.thethingsindustries.com/stack/)
- [LORIOT](https://loriot.io/)
- [ChirpStack](https://www.chirpstack.io/)

Alongside, the corresponding plugin for the selected LoRaWAN server needs to be installed in your Thinger.io instance.

## Get Started

### Installation

Look for the plugin in the [Thinger.io Plugin Store](https://marketplace.thinger.io/) and install it in your Thinger.io instance. Once the plugin is installed a new Product will be created for this device.

### Configuration

The Product is already preconfigured, check that the auto provision prefix matches the one selected in your LoRaWAN server plugin in Thinger.io, or change it to your desire.

### Usage

Start sending uplinks for autoprovisioning devices and buckets.
This product also provides a predefined dashboard and downlinks.
